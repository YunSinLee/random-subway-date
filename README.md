# 다음 역 데이트

`python3 -m http.server 18473 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:18473`에서 열어요.

노선별 역 연결과 좌표로 수도권 전철 노선도를 그립니다. `data/network.js`에 노선을 추가하거나 제거하면 필터에도 반영됩니다. 노선마다 역 ID 두 개씩 연결을 등록하고, 각 역의 `lines`에 해당 노선 ID를 넣습니다. 역 뽑기는 켜진 노선의 역을 중복 없이 대상으로 합니다. 지도 선은 역 좌표 사이를 직선으로 연결한 도식입니다. 배경은 브라우저가 현재 화면에 필요한 OpenStreetMap 타일을 불러옵니다. 외부 타일을 불러오지 못해도 노선과 역을 확인할 수 있습니다. 장소 버튼은 네이버 지도 검색으로 연결합니다.

노선도는 드래그해서 이동하고, 터치 화면에서는 두 손가락으로 확대하거나 축소할 수 있습니다. 뽑기 중에는 역 이름이 바뀌다가 열차가 당첨역에 멈춥니다. 모션 줄이기가 켜져 있으면 결과가 바로 표시됩니다.

역 데이터와 연결은 [subway-etl](https://github.com/minseok852/subway-etl#출처표시)에서 가져와 가공했습니다. 원천은 서울교통공사와 행정안전부가 공공누리 제1유형으로 개방한 [열차운행시각표](https://www.data.go.kr/data/15098251/fileData.do), [전국도시철도역사정보 표준데이터](https://www.data.go.kr/data/15013205/standard.do), [역간거리 및 소요시간](https://data.seoul.go.kr/dataList/OA-12034/F/1/datasetView.do), [환승역거리 소요시간 정보](https://data.seoul.go.kr/dataList/OA-13290/F/1/datasetView.do) 등입니다. 일부 역 연결은 원본 데이터의 추정치를 포함합니다.

현재 GTX-A는 운정중앙~서울역과 수서~동탄 두 구간을 각각 그립니다. [대도시권광역교통위원회 운영현황](https://molit.go.kr/mtc/USR/WPGE0201/m_37122/DTL.jsp)

데이터를 갱신하려면 subway-etl의 `station_nodes.csv`, `station_edges.csv`를 받은 뒤 다음을 실행합니다.

```sh
python3 scripts/import-network.py station_nodes.csv station_edges.csv
```

코스 화면은 `data/places.js`의 직접 등록 후보를 먼저 보여줍니다. 놀거리 후보를 등록하지 않은 역에서는 역 중심 기준 직선 1km 이내의 공공 공원과 전통시장을 가까운 순서로 표시합니다. 유형별로 최대 세 곳을 가져옵니다. 표기하는 거리는 각 장소의 대표 좌표까지의 직선거리이며, 시장 점포 수는 공공데이터에 값이 있을 때 표시합니다. 식당과 카페는 상가정보에서 역 중심 기준 직선 800m 이내의 후보를 유형별 최대 세 곳 표시합니다. 가까운 후보를 고르되 같은 주소의 매장만 나오지 않도록 서로 다른 주소를 우선합니다. 코스의 위치 그림에는 좌표가 있는 장소가 표시됩니다. 영업시간과 평점은 네이버 지도에서 확인할 수 있습니다. 후보가 없는 항목에는 네이버 지도 검색을 표시합니다.

현재 데이터에는 25개 노선의 고유 역 659곳이 있고, 모든 역에 놀거리·먹거리·카페 후보가 한 곳 이상 있습니다. 이 수치에는 역에서 버스나 셔틀로 이동하는 직접 등록 장소도 포함됩니다. 코스에는 해당 이동을 표시하며, 이 후보는 거리 조건을 선택해도 별도로 볼 수 있습니다.

뽑기에서 직선 800m 조건을 켜면 세 분류마다 거리를 확인할 수 있는 후보가 800m 안에 한 곳 이상 있는 역을 대상으로 합니다. 노선별로 조건을 충족하는 역 수를 표시하고, 노선도에서 제외된 역은 점선 테두리로 표시합니다. 처음 여는 코스에는 각 분류의 가까운 후보를 선택하고 후보 거리를 800m로 설정합니다. 저장한 코스가 있으면 저장 당시의 장소와 설정을 엽니다.

코스의 후보 거리는 300m, 500m, 800m, 1km 중에서 선택할 수 있습니다. 좌표가 없는 직접 등록 장소는 지도 검색 링크를 제공하며, 버스나 셔틀이 필요한 장소는 구간별 길찾기에 도착 장소와 확인한 운영기관 안내를 표시합니다.

코스의 공유 메뉴에서 방문 순서와 장소별 네이버 지도 링크를 복사할 수 있습니다. 브라우저에서 기기 공유를 지원하면 공유 앱도 열 수 있습니다. 로컬 실행 중에 공유 앱을 열 때는 받는 사람이 이용할 수 있는 장소 링크를 보냅니다.

공원·시장 후보는 [전국도시공원정보표준데이터](https://www.data.go.kr/data/15012890/standard.do)와 [전국전통시장표준데이터](https://www.data.go.kr/data/15012894/standard.do)의 2026-11-14 다운로드에서 가져왔습니다. 역 또는 장소 데이터 갱신 시 CSV나 JSON으로 다시 생성합니다.

```sh
python3 scripts/import-nearby.py parks 전국도시공원정보표준데이터.csv
python3 scripts/import-nearby.py markets 전국전통시장표준데이터.csv
```

직접 등록한 공공도서관의 좌표는 [전국도서관표준데이터](https://www.data.go.kr/data/15013109/standard.do)에서 가져왔습니다. 운영기관 안내를 확인한 장소는 카드에서 해당 안내를 열 수 있습니다.

식당·카페 후보는 소상공인시장진흥공단의 [2026년 9월 상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do)에서 서울·경기·인천·충남·강원 자료를 가져와 만들었습니다. 갱신할 때 전국 ZIP 원본을 전달합니다.

현재 앱에서 식당과 카페를 고를 때 사용하는 수치는 역과의 직선거리입니다. 카카오맵 평점 연동은 아직 구현하지 않았습니다.

```sh
python3 scripts/import-shops.py '소상공인시장진흥공단_상가(상권)정보_20260930.zip'
```

## 브라우저 검증

로컬 서버와 Google Chrome을 실행할 수 있는 환경에서 Playwright로 뽑기 연출과 모션 줄이기, 거리 조건에 따른 노선별 역 수, 모바일 노선도 조작, 코스 편집 및 공유를 확인합니다. 기기 공유는 테스트에서 브라우저 API를 대역으로 검증합니다.

```sh
npm install --prefix /tmp/subway-date-browser-check playwright
NODE_PATH=/tmp/subway-date-browser-check/node_modules node scripts/check-browser.cjs
```

데이터를 다시 생성한 뒤 `node scripts/check-data.cjs`를 실행하면 역 ID, 노선 연결, 장소 좌표와 거리 범위를 확인할 수 있습니다.
같은 명령은 장소 분류가 하나 이상 비어 있는 역이 많은 노선 다섯 곳과 분류별 누락 수를 보여줍니다. 보강할 역의 ID와 빠진 분류는 `node scripts/check-data.cjs --coverage-gaps`로, 노선별 전체 후보 수와 800m 조건 충족 수는 `node scripts/check-data.cjs --app-coverage`로 확인할 수 있습니다.
