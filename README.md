# 다음 역 데이트

오늘 어디서 만날지 고민될 때, 수도권 전철역을 하나 뽑아 둘이 가볼 곳을 정하는 웹 앱입니다. 뽑힌 역 주변의 놀거리·식당·카페를 골라 데이트 코스를 만들 수 있어요.

## 어떻게 쓰나요?

1. **오늘의 역 뽑기**를 누르면 역 하나가 나와요. 타고 싶은 노선이나 장소 후보 조건이 있다면 **뽑기 설정**에서 먼저 고를 수 있어요.
2. **코스 보기**에서 놀거리·식당·카페를 살펴보고, 마음에 드는 장소와 방문 순서를 골라요. 장소는 네이버 지도에서 확인할 수 있어요.
3. 만든 코스는 같은 브라우저에서 다시 열 수 있고, 방문 순서와 장소 링크는 함께 갈 사람에게 보낼 수 있어요.

가고 싶은 역이 이미 있다면 역 이름으로 검색하거나 노선도에서 직접 선택하세요.

## 내 컴퓨터에서 실행하기

Python 3가 설치되어 있다면 저장소를 내려받고 아래 명령을 실행하세요. 앱을 실행하는 데 API 키나 패키지 설치는 필요하지 않습니다.

```sh
git clone https://github.com/YunSinLee/random-subway-date.git
cd random-subway-date
python3 -m http.server 18473 --bind 127.0.0.1
```

브라우저에서 [http://127.0.0.1:18473](http://127.0.0.1:18473)을 열면 됩니다.

현재 구현 범위, 다음에 논의할 기능, 데이터 갱신 및 테스트 방법은 [개발 현황](docs/development.md)에 정리했습니다.
